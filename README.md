# Ctrl-V Terminal — Downloads

**Ctrl-V Terminal** is a tabbed **SSH + VNC** client for Windows, in the spirit
of the classic enhanced X-terminals. Its headline feature: **paste an image
straight into a remote terminal** — press `Ctrl+V` while the clipboard holds an
image and it's uploaded to the remote host over SFTP, with the file path typed
at your cursor, so tools like Claude Code can read it immediately.

Website: **https://ctrl-v-terminal.appgrid.eu**

## Download

Grab the latest installer from the [**Releases**](../../releases/latest) page:

- `Ctrl-V-Terminal-Setup-<version>.exe` — installer (per-machine).
- `Ctrl-V-Terminal-<version>.exe` — portable (no install).

## Free vs full version

The **free version** keeps up to **3 saved sessions**, with every feature
enabled. Unlock the full version for unlimited sessions and all future 1.x
updates — see the app's **Help → Unlock the full version**.

## Highlights

- Tabbed SSH terminals (xterm.js) with image-paste-over-SFTP.
- VNC remote desktop (direct, Apple/ARD auth, or tunnelled over SSH).
- Persistent tmux sessions, SFTP file browser with drag-to-desktop.
- Tear-off tabs into separate windows, live host status bar, PuTTY import,
  encrypted session export/import.
